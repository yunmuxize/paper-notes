% ---------- Research Experience ----------
\cvsection{Research Experience}

\noindent\hspace{5pt}{\fontsize{10.56}{12.3}\selectfont\color{black}%
Facilitating Low-Resource Complex In-network Traffic Classification and Incremental Update via LLM-inspired Hierarchical Trainining}%
\rightdate{\daterange{Feb 2025}{Nov 2025}}

\bodyfont
\para Objective: Targeting the scarce compute and heterogeneous-hardware deployment challenges of LLMs on edge network devices, designed an LLM-driven automated task-orchestration and lightweight hierarchical inference architecture that bridges high-level cloud semantic intelligence and line-rate data-plane performance.

\para Innovations: (1) Agent-based automated task orchestration: introduced LLM expert agents that decouple complex traffic-classification logic into hierarchical subtasks via Chain-of-Thought (CoT), and built a multi-agent Actor--Critic scheme that dynamically evaluates and iteratively refines decomposition strategies, fully replacing expert-driven manual feature engineering. (2) Multi-branch Neural Network Unit (NNU): designed a multi-branch NNU for data-plane hardware that distills LLM general reasoning into lightweight deployable matching rules; supports few-shot incremental updates for new traffic patterns while sustaining line-rate inference on programmable hardware, balancing accuracy and throughput.

\para Outcome: Delivered a closed-loop prototype from LLM-based planning to execution on \textbf{P4 switches}; submitted to IEEE Transactions on Networking (CCF-A; first author, under revision).

\vspace{2.6pt}
\projtitle{Elastic Traffic Analysis and Automated Deployment across Heterogeneous Data Planes}%
\rightdate{\daterange{Aug 2025}{Jan 2026}}

\bodyfont
\para Objective: Targeting resource heterogeneity and high retraining costs when deploying traffic-analysis models across heterogeneous data planes (Tofino/eBPF/BMV2), designed an automated compilation and elastic adaptation architecture based on model--hardware decoupling.

\para Innovations: 1) Elastic inference: proposed the Elastic Decision Tree (EDT) paradigm, fusing knowledge distillation with software--hardware co-pruning so that model structure dynamically adapts to pipeline stages and storage resources with zero retraining; 2) Constraint-driven orchestration: built a fine-grained regression-tree resource predictor (RMSE < 1.7\%) and a monotonic resource-search genetic algorithm (Hierarchical GA) that finds Pareto-optimal feature-matching and topology designs under TCAM/SRAM/Stage constraints.

\para Outcome: Developed a cross-platform orchestration prototype under an NSFC project; validated in real Tofino/BMV2 environments, improving deployment success rate by 100\% over SOTA in extremely resource-constrained scenarios; to be submitted to IEEE ToN (CCF-A).

\vspace{2.6pt}
\projtitle{Elastic Aggregation and Efficient Communication for Large-Scale Distributed Training}%
\rightdate{\daterange{Feb 2026}{Present}}

\bodyfont
\para Objective: Targeting communication bottlenecks and single points of failure in parameter synchronization for large-scale distributed training, designed an elastic aggregation architecture based on cross-node resource borrowing that organizes fragmented idle resources into transient buffer pools, providing low-overhead fault-tolerant paths for partial communication failures.

\para Innovations: (1) Dual-role path locking with single-hop forwarding: a source/guest path-locking mechanism that strictly reuses paths for the same tuple after first-packet adjudication, with a sealed state machine for per-tuple slot reclamation, ensuring low-latency, highly reliable parameter synchronization. (2) Directed recovery with lightweight protocol: recovery is localized to task granularity---only partial data is pulled from affected nodes, avoiding global retransmission; a lightweight protocol header integrates state management for efficient synchronization within limited bandwidth.

\para Outcome: A new design paradigm for elastic fault tolerance in in-network aggregation, distinct from the centralized fallback paths of existing distributed-training communication systems.
